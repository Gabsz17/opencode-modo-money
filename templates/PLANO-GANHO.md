# PLANO-GANHO.md — template do plano financeiro educacional

> Copie este arquivo para `docs/dinheiro/<objetivo>/PLANO-GANHO.md` no início de cada plano via `/ganhar`.
> Em uso normal o `moneymaker` é dono da trilha; em missões de obra, mudanças sobem via relatório ao orquestrador (single-writer de `PLANO.md`/`API.md`).
> Este plano é EDUCACIONAL: sem promessa de lucro, sem recomendação personalizada de investimento, sem insider/pirâmide. Sem fonte oficial = `não confirmado`. Cotação/relatório sempre com data+fonte.
> Nao e recomendacao de investimento. Ver docs/dinheiro/disclaimer.md.

## 8. Disclaimer

- Este material é educacional e não constitui recomendação de investimento, promessa de lucro ou garantia de resultado. Decisões são do usuário, por sua conta e risco.
- Fontes oficiais prevalecem: BCB, CVM, B3, Tesouro Direto, gov.br/SEBRAE. Docs de corretora/exchange só como referência operacional.
- Sem segredo no repo: chaves só via env (`{env:NOME}`), `.env` fora do git. Dados sensíveis (CPF, saldo exato, chave real) nunca entram.
- Dúvida regulatória/tributária → contador/planejador certificado + fonte oficial, marcado `não confirmado` até lá.
